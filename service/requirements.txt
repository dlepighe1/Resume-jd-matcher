# Python scoring service. Serves the fine-tuned MPNet + Platt calibrator over HTTP.
# Deployed on Railway from the root Dockerfile; Next.js calls it via SCORING_SERVICE_URL.
# The Dockerfile installs the CPU build of torch first, from PyTorch's own index.
#
# The service imports the model code that already lives in this repo: src/text_utils.py
# (the exact preprocessing the model was trained under) and app/explain.py (skill-gap
# analysis), so the served scores match the research numbers rather than reimplementing
# the pipeline and drifting from them.
#
# Pinned for the same reason requirements.txt is: the whole argument for this service is
# that it returns the numbers the study measured, and a floating dependency range is a
# silent way for that to stop being true between one deploy and the next.
